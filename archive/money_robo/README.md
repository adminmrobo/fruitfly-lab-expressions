# 보관: Money-Robo (2026-11-04 교체)

이 폴더는 연구실 로봇이 **주판봇(AbaBot)**으로 바뀌기 전의 Money-Robo 자료입니다.

- Money-Robo는 **(주)M-Robo의 회사 캐릭터**(상표 "money-robo", 회사 로고 로봇)입니다.
- 「초파리 연구실」은 저작자 개인의 콘텐츠이므로, 새 페이지·새 그림에서는 이 캐릭터를 쓰지 않습니다.
- 이미 공개된 옛 페이지를 고칠 때 대조용으로만 남겨 둡니다.
