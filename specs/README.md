## 사용 순서
1. 원하는 캐릭터·표정 명세의 **7절 프롬프트**를 복사합니다.
2. 해당 캐릭터의 원본 참조 이미지를 레퍼런스로 함께 넣습니다 (원본 대응 표정은 그 칸을 1순위로).
3. 캐릭터마다 **E13**을 먼저 생성해 승인받은 뒤, 이후 표정의 2차 레퍼런스로 씁니다.
4. 결과물은 명세의 `image_file` 경로에 저장하고 `image_status`를 업데이트합니다.
5. 자동화할 때는 각 폴더의 `expressions.json`을 씁니다 (`prompt_en`, `negative_en` 포함).
