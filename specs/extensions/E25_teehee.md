# E25 · 데헷 (Teehee (Tehe-pero)) — 확장 표정 공통 정의

E01~E24는 모든 캐릭터가 같이 쓰는 **공통 세트**이고, `E25` 이후는 일부 캐릭터만 갖는 **확장 표정**입니다. 공통 세트의 번호·구성은 그대로 둡니다.

| 항목 | 내용 |
|---|---|
| 대상 | 하루 · 시아 · 모아 (여성 캐릭터 3명, 헤어 벡터와 같은 범위) |
| 제외 | 박사 · 주판봇 · 초파리 · 미공개 X1~X3 |
| 뜻 | 실수를 들킨 뒤 귀엽게 얼버무리는 인터넷 밈 '데헷(테헤페로)' |
| 참고 범위 | 밈의 **포즈만**: 윙크 + 혀끝 + 고개 기울임 + 얼굴 가까운 손. 특정 작품 캐릭터의 얼굴·머리·의상은 참고하지 않음 |

## 공통 부위 지시
| 부위 | 지시 |
|---|---|
| 눈썹 | 윙크한 쪽은 살짝 내려가고, 다른 쪽은 편안한 아치 |
| 눈 | 한쪽 눈은 웃는 곡선(^)으로 감아 윙크, 다른 눈은 뜨고 정면을 봄 · 하이라이트 유지 |
| 입 | 입꼬리를 올린 장난스러운 미소, 혀끝만 입꼬리 쪽으로 살짝 내밂 |
| 볼·피부 | 옅은 분홍 홍조 줄무늬 |
| 머리·자세 | 고개를 한쪽으로 살짝 기울임 |

## 캐릭터별 손 동작 (성격 반영)
| 캐릭터 | 손·제스처 | 이펙트 |
|---|---|---|
| 하루 | 한 손으로 V사인을 만들어 윙크한 눈 옆에 댐 (밈 대표 포즈) | 작은 반짝이 2개 |
| 시아 | 검지 하나로 볼을 콕 찌름 (손등이 보이게, 얼굴 가까이) | 없음 (조용한 캐릭터라 이펙트를 아낌) |
| 모아 | 가볍게 쥔 주먹으로 자기 머리를 '콩' 두드림 (테헤페로 원형 동작) | 머리 위 작은 '콩' 충격 별 1개(글자 없이 모양만) |

> 세 명 모두 같은 V사인으로 맞추고 싶으면 각 명세 7절 프롬프트의 손 부분을 `one hand making a peace V sign right next to the winking eye`로 바꾸면 됩니다.
