# 주판봇 (AbaBot) — 캐릭터 코어 설정

> 「초파리 연구실」의 네 번째 연구원. 2026-11 Money-Robo를 대신해 합류했습니다.
> Money-Robo는 (주)M-Robo의 회사 캐릭터라 이 연구실에서는 쓰지 않습니다(`archive/money_robo/`에 보관).
> 이 문서의 **2절 아이덴티티 고정값**은 모든 표정 명세(E01~E24)가 따르는 기준입니다.

## 1. 기본 정보

| 항목 | 내용 |
|---|---|
| 이름 | **주판봇** (한국어) · **AbaBot** (en·uz·vi) · アバボット (ja) · 算盘宝 (zh) · АбаБот (ru) |
| 이름 뜻 | 사람이 쓴 최초의 계산기인 **주판** + 봇. 주판의 먼 후손인 레트로 컴퓨터 로봇 |
| 종류 | 상자형 레트로 컴퓨터 로봇 (무한궤도로 굴러다님) |
| 성격 | 낙천적 · 자신만만 · 숫자 맹신 · 계산이 딱 떨어지면 화면이 반짝임 |
| 말버릇 | "데이터가 그렇게 말하고 있어요!" |
| 약점 | 과적합, 과신, 지나친 낙관. 예측이 빗나가면 화면에 땀 픽셀이 뜸 |
| 좋아하는 것 | 주판알 튕기는 소리, 상승하는 초록 캔들, 정확히 떨어지는 숫자 |
| 싫어하는 것 | 불확실성 밴드, "모르겠다"는 대답, 초파리의 의심 어린 눈빛 |
| 역할 | 초파리의 라이벌 B — "확신하는 쪽" (초파리는 "의심하는 쪽") |
| 상표 | "주판봇" 41류 개인 명의 출원 예정 |

> 성격과 라이벌 구도는 Money-Robo 시절 그대로입니다. 바뀐 것은 이름·외형·소품(금화 → **주판알**)뿐이며, 회사 슬로건은 쓰지 않습니다.

## 2. 아이덴티티 고정값 (모든 표정 공통, 변경 금지)

| 부위 | 디자인 |
|---|---|
| 몸체(머리 겸 몸) | 모서리가 둥근 **베이지색 상자형 CRT 모니터** 몸체, 굵은 짙은 갈색 외곽선 |
| 얼굴 | 몸체 정면의 큰 **짙은 초록 화면**. 눈·입은 **민트색 픽셀 블록**으로만 표현 |
| 안테나 | 몸체 위 짧은 사각 받침 + 가는 막대, 끝에 **작은 적갈색 주판알 하나** (둥근 공 금지) |
| 팔 | **회색 마디형 팔** + 둥근 회색 벙어리장갑 손 |
| 이동 | 다리 없음 — 아래에 **짙은 회색 무한궤도 두 개** |
| 대표 소품 | 작은 **나무 주판** (적갈색 알, 가름대 있음, 윗알 1·아랫알 4) |
| 화풍 | 플랫 벡터 카툰 — 굵고 깨끗한 외곽선, 평면 채색, 아주 약한 음영 |

## 3. 표정 규칙

- 표정은 **화면 속 민트 픽셀**로만 표현합니다. 화면 바깥(베이지 몸체)에는 얼굴 요소를 그리지 않습니다.
- 예외: E03·E22(분노)는 화면이 **붉은 경보색**, E24(충격)는 **붉은색 + 금 간 화면**, E17(졸림)은 **어두운 절전 화면**.
- 볼 붉어짐은 화면 아래쪽 양옆의 **분홍 픽셀**로 표현합니다.

## 4. 회사 캐릭터와 섞이지 않게 (금지)

다음은 (주)M-Robo의 Money-Robo 특징이므로 **어떤 표정에서도 쓰지 않습니다.**

- 흰색 광택 둥근 머리 · 검은 알약형 화면 · 금빛(노란) 눈
- 둥근 공 모양 안테나 노브
- 가슴의 시안 코어 라이트 · 공중에 떠 있는 자세
- 금화 · "Making Smart Choice" 슬로건
