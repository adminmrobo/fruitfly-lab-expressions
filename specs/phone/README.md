# 폰 배경 셀카 3컷 벡터 (phone v1.4, 2026-11-19)

여성 캐릭터 **하루·시아·모아**에게만 적용하는 축입니다(헤어·확장 표정과 같은 범위, 미공개 X1~X3 제외). 세로 폰 배경으로 쓰는 **3컷 만화 한 장**을 캐릭터마다 **픽셀판·벡터판** 두 가지로 둡니다.

- 갤러리: [`phone.html`](../../phone.html) · 설정값: [`phone.json`](phone.json) · 프롬프트: [`PROMPTS.md`](PROMPTS.md)

## 컷 구성

| 컷 | 자리 | 장면 |
|---|---|---|
| P1 | 위 왼쪽 | 만세: 눈 감고 활짝 |
| P2 | 위 오른쪽 | 옆모습: 폰 카메라를 알아채고 놀람 |
| P3 | 아래 큰 칸 | 셀카 클로즈업: 브이, 고양이 입, 하트 하이라이트 눈 |

- 크기 9:16 (생성본 768×1360). **맨 위 12%는 잠금화면 시계 자리로 비워 둡니다.**
- 글자·말풍선은 그림에 넣지 않습니다. 대사가 필요하면 페이지에서 HTML 글자로 얹습니다.

## 참고 범위

사용자가 준 참고 이미지 1장(2026-11-19)에서는 **컷 구성과 연출만** 빌립니다(만세 → 옆모습 놀람 → 셀카 브이). 그 그림 속 캐릭터의 머리 모양·의상(트윈테일·청록 머리·넥타이·민소매)은 쓰지 않고, 참고 이미지는 생성 도구에 첨부하지 않으며 저장소에도 넣지 않습니다. 연구실 식구는 각자의 정본(E13·원본 시트) 모습 그대로입니다.

## 장비 옵션 (벡터판만, v1.1 · 2026-11-19)

| ID | 장비 | 규칙 |
|---|---|---|
| G0 | 없음 | 정본 그대로 (픽셀판·벡터판 기본) |
| G1 | 헤드셋 | 얇은 머리띠 + 둥근 이어컵 + 작은 붐 마이크, 캐릭터 색(하루 남색·라벤더, 시아 숯색·은회색, 모아 카멜·크림). 하루는 머리띠가 번 2개 사이로 지나감 |
| G2 | 마스크 | 흰 주름 마스크. P1·P2는 코·입을 덮고, P3는 턱 아래로 내려 미소가 보이게 |
| G3 | 안전모 | 공장 벡터 U01과 같은 노란 안전모 + 턱끈. 하루는 번을 안전모 안에 넣고, 모아는 흰 프릴 머리띠를 벗음(공장 규칙과 같음) |

- 헤드셋은 둥근 이어컵의 일반 디자인으로 그립니다. 참고 이미지 속 헤드셋 모양(검정·분홍 사각 귀 장식)만 따라 하지 않습니다.
- 한 그림에는 장비를 하나만 씁니다. 세 컷 모두 같은 장비를 착용합니다.

## 그림 반영 (2026-11-19)

15장 모두 Genspark로 생성해 반영했습니다(768×1360). 컷 45장(`PH1_p1~p3_…`)은 가로·세로 흰 거터를 자동으로 찾아 잘랐습니다.

| 재생성 권장 | 이유 |
|---|---|
| 하루 픽셀판 · G0 · G1 · G2 | P3 팔 3~4개(양손 브이 + 셀카 팔) |
| 모아 픽셀판 · G1 · G2 | P3 팔 3~4개(양손 브이 + 셀카 팔) |

시아(한 손 브이 + 폰 든 팔)는 5장 모두 정상, 하루 G3·모아 G0·G3도 정상.

**v1.3 수정:** 양손 브이에 셀카 팔까지 그려지는 문제라서, 하루·모아의 P3를 **폰을 작은 삼각대에 세워 타이머로 찍는 장면**으로 바꿨습니다(양손 브이 유지, 두 팔꿈치는 몸 쪽으로 내림, 카메라 쪽으로 뻗은 팔 없음). 하루·모아 네거티브에 "outstretched arm toward the camera, selfie arm"을 더했고, 공통 네거티브에 "four arms"를 더했습니다.
