# Money-Robo 시즌 — 캐릭터 설정서

> 「초파리 연구실」 세계관에 새 캐릭터 **Money-Robo**가 합류합니다.
> 이번 시즌의 주제는 **생성형 AI · 주가 예측 · 비트코인 가격 예측 · 통계학**이고,
> 그 중심에는 **초파리 vs Money-Robo**의 라이벌 관계가 있습니다.

---

## 1. 등장 캐릭터 (4인)

| 캐릭터 | 한 줄 소개 | 판단 기준 | 시즌 내 역할 |
|---|---|---|---|
| **박사** | 자신만만한 치비 과학자 | 이론과 큰소리 | 해설자 · 심판 · 사회자 |
| **조수** | 실제로 일을 다 하는 연구원 | 꼼꼼한 실험과 기록 | 실험 진행 · 점수 기록 |
| **초파리** | 작지만 날카로운 연구원 | 호기심과 생물학적 직관 | 라이벌 A — "의심하는 쪽" |
| **Money-Robo** | 돈과 숫자를 사랑하는 부유형 로봇 | 차가운 숫자와 수익 | 라이벌 B — "확신하는 쪽" |

## 2. Money-Robo 상세 설정

### 2-1. 기본 정보

| 항목 | 내용 |
|---|---|
| 이름 | **Money-Robo** (머니로보) |
| 슬로건 | *Making Smart Choice* |
| 종류 | 부유형(호버링) 치비 로봇 |
| 성격 | 낙천적 · 자신만만 · 숫자 맹신 · 돈 이야기에 눈이 반짝임 |
| 말버릇 | "데이터가 그렇게 말하고 있어요!" |
| 약점 | 과적합, 과신, 지나친 낙관. 예측이 빗나가면 화면 얼굴에 땀 픽셀이 뜸 |
| 좋아하는 것 | 금화, 상승하는 초록 캔들, 정확히 떨어지는 숫자 |
| 싫어하는 것 | 불확실성 밴드, "모르겠다"는 대답, 초파리의 의심 어린 눈빛 |

### 2-2. 외형

| 부위 | 디자인 |
|---|---|
| 머리 | 크고 둥근 사각형, 광택 있는 흰색, 굵은 검은 외곽선 |
| 안테나 | 짧은 막대 위 작은 원형 노브 |
| 얼굴 | 검은 알약형 스크린 — **금빛 원형 눈 2개 + 금빛 곡선 미소** |
| 몸통 | 작고 둥근 흰 몸통, 가슴에 검은 타원 패널 + **시안 알약형 코어 라이트** |
| 팔 | 짧고 둥근 팔, 손가락 없음 |
| 다리 | 없음 — 아래에 검은 타원 그림자를 두고 떠 있음 |

**컬러 팔레트**

| 색 | 용도 |
|---|---|
| 광택 화이트 | 머리·몸통 |
| 블랙 | 외곽선·스크린·가슴 패널 |
| 골든 옐로 | 눈·미소·금화 |
| 시안 | 가슴 코어 라이트 |

### 2-3. 표정 9종 (3×3 시트)

표정은 **스크린 얼굴의 금빛 픽셀 눈**으로 표현합니다.

| | 1열 | 2열 | 3열 |
|---|---|---|---|
| **1행** | 무표정 | 부드러운 미소 | 짜증(일자 눈) |
| **2행** | 울음(픽셀 눈물) | 경악(동그랗게 커진 눈) | 능글(금화 반짝임) |
| **3행** | 졸음(감은 눈 + 방울) | 부끄럼(분홍 볼 픽셀) | 분노(빨간 경보 빛) |

> 3×3 격자 형식은 사용자가 첨부한 표정 시트(은발 캐릭터)의 **레이아웃만** 참고했습니다. 그 캐릭터 자체는 등장하지 않습니다.

## 3. 라이벌 구도 — 초파리 vs Money-Robo

```
        [초파리]                         [Money-Robo]
   호기심 · 의심 · 직관      VS      숫자 · 확신 · 수익
   "정말 그럴까?"                    "데이터가 그렇게 말해요!"
   작은 돋보기 하나                   도구 벨트 + 슈퍼컴퓨터
   느리지만 정확한 확인               빠르지만 가끔 폭주
```

| 관점 | 초파리 | Money-Robo |
|---|---|---|
| 무기 | 작은 돋보기, 날개 | 금화, 캔들 차트, 레이저 눈 |
| 강점 | 이상치·착각을 잘 잡아냄 | 대량 계산, 속도 |
| 약점 | 너무 신중해서 결정이 느림 | 과적합, 과신, 환각 |
| 웃음 포인트 | 의기양양한 팔짱 | 땀 픽셀이 뜨는 스크린 얼굴 |

**관계의 규칙**

1. 두 캐릭터는 매 장면 **경쟁**한다 — 경주, 대결, 점수판.
2. **승패는 고정하지 않는다.** 주제에 따라 이기는 쪽이 바뀐다.
   - 초파리가 이기는 주제: 환각 체크, 과적합, 상관≠인과, 이상치
   - Money-Robo가 이기는 주제: 대량 계산, 속도, 분산이 작은 예측
3. 각 테마의 **마지막 컷은 화해·교훈**으로 끝낸다(악수, 엄지척, 안전망).
4. 박사와 조수는 **심판·해설·기록** 역할로 둘을 중재한다.

## 7. 콘텐츠 주의사항

이 시리즈는 **교육용 코미디**입니다. 주가·비트코인 장면은 예측 기법을 설명할 뿐 투자 권유가 아닙니다.
그래서 두 금융 테마의 마지막 컷(`s12`, `b12`)은 일부러 **"미래는 불확실하다 · 리스크 관리가 먼저다"**는 교훈으로 끝냈습니다.
